# App Contract Tests

This is a historical test tree. Do not add new technical-category paths such as
`frontend/` or `infra/`.

New chart tests belong under `tests/charts/` and should use current product names
while mirroring the chart or rendered contract under test. Cross-chart security
contracts belong under `tests/security/`, release package tests under
`tests/releases/`, and repository validation under `tests/validation/`.

Existing files below this directory remain only until they are migrated as part
of a focused test change.
