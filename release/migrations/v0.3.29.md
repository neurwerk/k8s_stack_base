# v0.3.29 upgrade guidance

Stable upgrades are supported after the required preparation. Downgrade is unsupported; recovery is forward-fix. No alpha promotion revisions are declared.

Follow the [upgrade checklist](../../docs/releases/upgrade-0.3.29.md) before reconciliation for grouped-only values, ordered MCP metadata and URL migration, matching LibreChat selection, Valkey storage preservation and verification.
