# v0.3.43 adoption

Deploy this release before restoring an external Docling runtime that emits a newer document schema by default. extProc requests schema 1.10 through Docling's official version negotiation and still rejects unsupported output.

Valid partial extraction, including nonempty subsets of PDF pages, is forwarded with a visible warning even when optional notices are disabled. Empty or malformed extraction remains rejected. Partial extraction is rejected for structured or tool-enabled requests, and replies without a safe visible warning are rejected or aborted.

A warning identifies incomplete extraction; it does not establish complete or independently verified document content. An HTTP success alone is not content-validation evidence.

Keep existing credentials, model files, volumes, page allowances, and endpoint settings. No data migration is required. Verify a document request through Gateway after reconciliation, then verify the external runtime again after any separately approved restoration.

Recovery is a forward fix; do not move the platform tag backward.
