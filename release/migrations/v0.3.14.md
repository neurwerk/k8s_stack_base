# v0.3.14 Migration

## Support

- Stable upgrades: Supported.
- Upgrades from alpha revisions: None.
- Downgrades: Unsupported.

## Breaking Changes

Before upgrading, run openbao-stack-setup 0.2.20 reconciliation and wait for
`OpenBao reconciliation completed.` Existing credentials and persistent data are preserved.

## Recovery

Forward-fix with the corrected prerequisite; no runtime artifact or persistent-data migration is included.
