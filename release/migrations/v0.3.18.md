# v0.3.18 upgrade notes

Langfuse v4 uses fresh storage. Previous Langfuse projects, traces, prompts, datasets, and other data are not migrated. The operator confirmed existing clients do not need to retain that data.

Before Langfuse v4 reconciles, verify cert-manager is Ready, then install ClickHouse Operator Helm chart `0.0.5` from `oci://ghcr.io/clickhouse/clickhouse-operator-helm` in `clickhouse-operator-system` using the intended Kubernetes context. Verify the operator is Ready and the `clickhouseclusters.clickhouse.com` and `keeperclusters.clickhouse.com` CRDs are Established. The operator is a prerequisite in the release manifest, not a Base Flux package.

The API-key bridge moves from SQLite to an empty PostgreSQL database. Existing SQLite keys are not imported; the operator confirmed no relevant existing keys need copying. Check the bridge before removing only its retired SQLite claim. Preserve unrelated storage.

Before adopting this release, reconcile OpenBao with `openbao-stack-setup` `0.2.23` from the exact Tooling source in the release manifest. Reconcile the required Studio and API-key bridge database credential Secret-sync packages after their SecretStores are ready and before the application updates; check all four target Secrets are ready. Dify 1.17.1 runs its schema migration automatically; do not reset Dify databases, Redis, or files solely for this upgrade.
