# Platform v0.3.4

## Support

- Stable upgrades: Supported.
- Supported alpha source revisions: None.
- Downgrade: Unsupported.

Prerequisites and package exclusions are unchanged from v0.3.3. Review every
crossed release's migration instructions before adoption.

## Breaking Changes

See the release notes in CHANGELOG.md for breaking changes and required actions.

## Recovery

Recovery classification: Forward fix.

Role provisioning changes persistent permissions; reverting Git does not restore
them. Require independently tested backups and recovery before adoption. Offline
release checks do not prove a live transition or recovery.
