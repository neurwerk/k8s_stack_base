# Platform v0.1.0

## Support

- Fresh installation: Supported.
- Supported source versions: None.
- Upgrade from unversioned `main`: Unsupported.
- Downgrade: Unsupported.

This is the first aggregate platform release. Existing declarations from
unversioned `main` have no tested transition into this release.

## Prerequisites

Install the exact CRD and controller prerequisites listed in
`release/manifest.yaml`. Provision separate read-only Git authentication and
release trust Secrets in `flux-system`. The release trust Secret must contain
the expected SSH public signing key and must be named
`k8s-stack-release-trust`.

## Client Actions

Set `GitRepository/k8s-stack.spec.ref.tag` to `v0.1.0`, remove the `main` branch
reference, and enable `verify.mode: Tag` using `k8s-stack-release-trust`.

Required client value changes: None.

Required confidential value changes: None. Do not commit either Flux Secret.

## Stateful And API Effects

This baseline creates the stateful services and CRDs represented by the default
platform stages on a fresh cluster. It does not define a transition for existing
databases, OpenBao, Rook/Ceph, PVCs, K3s state, or stored CRD versions.

## Pre-Deployment Checks

1. Verify the expected cluster context and stable cluster identity.
2. Verify all manifest prerequisites and published workload images.
3. Verify the signed tag and release manifest before updating a client.
4. Confirm independent recovery custody and storage prerequisites.

## Post-Deployment Checks

Inspect both Git sources, all Flux Kustomizations, all HelmReleases, warning
events, and affected workload logs. Complete the empty-cluster acceptance run
before onboarding another client.

## Recovery

Recovery classification: Replacement restore.

A Git declaration revert is not a state rollback. Because no source transition
is supported, rebuild a separate environment and restore only through a
component's verified recovery procedure if state has already been created.

## Exclusions

- LibreChat RAG is not part of the default application stage and is excluded
  until its deployment-readiness and effective-render contracts are complete.
- LibreChat Code Interpreter is excluded because its first-party runtime images
  have not been released.
