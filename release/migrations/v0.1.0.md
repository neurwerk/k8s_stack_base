# Platform v0.1.0

This is the initial aggregate platform release.

## Support

- Fresh installation: Supported.
- Supported source versions: None.
- Downgrade: Unsupported.

## Prerequisites

- Use an empty target cluster.
- Install every prerequisite and CRD version declared in `release/manifest.yaml`.
- Authenticate the platform signing fingerprint independently.
- Prepare client values and OpenBao bootstrap inputs without committing Secrets.

## Client Actions

After publication, pin the client platform source to signed tag `v0.1.0`, set
adoption mode to `fresh-install`, compose the default packages, and complete the
documented OpenBao bootstrap before expecting applications to become Ready.

## Stateful And API Effects

The release creates initial Kubernetes, database, object, and secret state. It
does not import or migrate state from an earlier platform revision.

## Pre-Deployment Checks

1. Verify the target has no platform application state.
2. Verify the signed tag, manifest, immutable image pins, and declared exceptions.
3. Confirm client values, storage, DNS, certificates, and external credentials.

## Post-Deployment Checks

1. Inspect Flux sources, Kustomizations, and HelmReleases.
2. Inspect warning events and affected workload logs.
3. Verify authentication, storage, secret synchronization, and application readiness.

## Recovery

Recovery classification: Replacement restore.

Rebuild an empty replacement environment from `v0.1.0`, then restore only
independently verified backups created after the initial deployment. Do not use
a Git or Helm rollback as a state rollback.

## Exclusions

- LibreChat RAG and Code Interpreter packages remain excluded.
- Time-bounded LibreChat and DocumentDB exceptions remain recorded in the
  release manifest.
