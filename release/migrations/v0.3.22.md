# v0.3.22 upgrade notes

- **Legacy Dify:** Base no longer supplies its releases or namespace. Before adopting this tag on a client that still uses Base-managed Dify, plan a separately reviewed retirement or add-on handoff. Inspect the actual Flux inventory, namespace, persistent volumes, database dependencies, and backups; changing the source can stop workloads or prune state. Do not delete shared data as part of the Base release.
- **Active Directory:** Federation is now an optional stage, not part of the default applications stage. Existing installations need the maintenance-mode, single-owner handoff in [Base's Active Directory instructions](https://github.com/neurwerk/k8s_stack_base/blob/4a3ee1ebb5b5bc6b237540f4abbd08024fdc5609/README.md#optional-active-directory-stage) before changing the platform source. Do not run both reconcilers at once.

Neither change selects an add-on or authorizes client adoption. Check the signed release manifest and the actual client state before any upgrade.
