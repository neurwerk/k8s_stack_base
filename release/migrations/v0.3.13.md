# v0.3.13 Migration

## Support

- Stable upgrades: Supported.
- Upgrades from alpha revisions: None.
- Downgrades: Unsupported.

## Breaking Changes

Deploy the signed platform and wait for extProc 0.11.2 and PII Engine 0.10.1 readiness before raising client RPC limits or selecting `imageForwarding: if-policy-allows`; preserve existing data and credentials.

## Recovery

Configuration revert.
Revert client capacity and image-forwarding values while retaining the new platform tag; no persistent-data migration is included.
