# v0.3.13 Migration

## Support

- Stable upgrades: Supported.
- Upgrades from alpha revisions: None.
- Downgrades: Unsupported.

## Breaking Changes

Before upgrading, run openbao-stack-setup 0.2.18 reconciliation to provision the required OpenSearch Dashboards credentials.
Deploy the signed platform and wait for extProc 0.11.3 and PII Engine 0.10.1 readiness before raising client RPC limits or selecting `imageForwarding: if-policy-allows`; preserve existing data and credentials.

## Recovery

Configuration revert.
Revert client capacity and image-forwarding values while retaining the new platform tag; no persistent-data migration is included.
