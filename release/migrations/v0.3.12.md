# v0.3.12 Migration

## Support

- Stable upgrades: Supported.
- Upgrades from alpha revisions: None.
- Downgrades: Unsupported.

## Breaking Changes

None. HTTPS remains the default. See CHANGELOG.md for the release changes.
From v0.3.11, adopt the signed platform release before setting
`docling.inference.allowHttp: true` and an HTTP URL with its matching port.
Existing HTTPS values require no changes. No image, database, CRD or storage
migration is included. Preserve existing credentials and persistent data.

Rendered tests verify default HTTP rejection, explicit HTTP acceptance, matching
ports, and unchanged service TLS. After adoption, verify Docling readiness and
a synthetic conversion against the selected backend.

## Recovery

Configuration revert. Restore the previous inference URL, model and port, and
remove the HTTP opt-in while retaining the new platform tag. This changes only
configuration; it does not roll back persistent state.
