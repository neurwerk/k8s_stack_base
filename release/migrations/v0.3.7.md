# Platform v0.3.7

## Support

- Stable upgrades: Supported.
- Supported alpha source revisions: None.
- Downgrade: Unsupported.

Upgrade stable installations from `v0.3.6`. If skipping versions, also follow
each skipped release's instructions. Alpha environments stay on alpha.

## Breaking Changes

1. Before upgrading, verify backups and a tested restore. Test the planned
   upgrade and recovery in a disposable environment.
2. Review `platform-admin` access. Use
   `authKeycloak.platformAdminRoleExclusions` to exclude applications; older
   charts do not support this setting. Keep model/MCP grants separate. After
   upgrading, sign in again and verify access before removing old memberships.
   Exclusions do not remove direct grants or revoke existing sessions.
3. Upgrade PII Engine/model-sync and extProc together to the release's pinned
   images. Remove or update client image overrides that would retain old versions,
   including Studio overrides. Do not change model bundles.
4. After upgrading, check Flux and application health, database provisioning,
   worker connectivity and database isolation. Test Studio, API-key access, and
   streamed model/tool calls, including long tool descriptions and usage reporting.

No new OpenBao reconciliation is needed for an already-configured `v0.3.6`
installation using supported packages. Forgejo, WireGuard, maintenance, LibreChat
RAG and Code Interpreter remain excluded from stable use; do not enable them as
part of this upgrade. See the [changelog](../../CHANGELOG.md#037---2026-09-15)
for changes and known limitations.

## Recovery

Recovery classification: Forward fix.

Do not downgrade or treat a Git revert as a data restore. Preserve databases,
credentials and model storage. If a forward fix is unsafe, stop and follow the
approved restore procedure using verified backups.
