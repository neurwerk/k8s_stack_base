# Platform v0.3.7

## Support

- Stable upgrades: Supported.
- Supported alpha source revisions: None.
- Downgrade: Unsupported.

The stable policy permits strictly forward exact stable tags, including
`v0.3.6` to `v0.3.7`; review all crossed migrations when skipping versions.
Fresh installation requires a verified empty or replacement environment.
The permanent alpha environment is not being promoted to stable.

## Recovery

Recovery classification: Forward fix.

Do not downgrade persistent state or treat a Git/Helm revert as a restore.
Preserve complete authentication and operations PostgreSQL instances, OpenBao
and application credentials, API-key storage, PII state and authoritative model
objects. Optional Forgejo shares the operations database recovery domain and
also needs its retained PVC and durable secrets. If a forward fix is unsafe,
stop and use a separately reviewed component/replacement restore procedure with
verified independent backups; no restore is proven by this preparation.

For separately selected optional packages, stop WireGuard before peer, key or
target changes and recover with no peers when the approved list is untrusted.
Native Forgejo credentials require separate offboarding. Deactivate maintenance
scopes and complete operator-resource cleanup before removing static resources;
Flux pruning does not remove operator-owned routes or restore application data.
