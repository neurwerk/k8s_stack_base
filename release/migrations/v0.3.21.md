# v0.3.21 upgrade notes

Before adopting this release, use `openbao-stack-setup` `0.2.24` from the exact Tooling source in the release manifest and reconcile the catalog for the intended client. The catalog copies the Langfuse project credentials into dedicated Studio fields without replacing existing values; conflicting copies stop reconciliation.

Studio's personal LLM and MCP activity is off by default. For a client that enables `frontendStudio.api.llmLogs.enabled`, finish credential reconciliation first, then verify the Studio ExternalSecret, API and Web readiness, and a self-only activity read after adoption. The source change does not authorize another client's adoption or cluster reconciliation. Recovery is forward-fix; reverting Git does not undo persistent changes.
