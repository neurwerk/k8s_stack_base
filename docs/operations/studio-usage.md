# Studio usage cutover

Adopt the Studio API, Web and collector images together using the exact pins in the selected manifest. Before adoption, reconcile the manifest's standalone `stack-setup` release to prepare separate collector and reporting-reader passwords, then provision `studio_usage` through the operations PostgreSQL chart. The API's initialization container creates the reporting schema before the API starts.

The event-accounting upgrade resets only the previous MCP summaries once and records a separate MCP activation time; obtain approval for that reset before adoption. Existing LLM history is preserved. AgentGateway emits metadata-only invocation records for caller-facing MCP tool calls, and Fluent Bit delivers them to OpenSearch. The collector deduplicates invocation IDs and replaces hourly and daily summaries transactionally.

Supply client pricing under `frontendStudio.usage.mcpPricing` in the existing Studio values. Prices are USD per 1,000 tool calls; append dated revisions on reporting-hour boundaries. Set `default_rate: 0` for free servers and declare paid server accounts explicitly. An explicit null tool price blocks the server default, and zero means free. Brave web search and LLM Context cost 5 USD per 1,000 calls; leave unreviewed Brave tools unpriced and apply credits only after confirming account eligibility. Provider fees, allowances and credits apply once per billing account; tool costs and adjusted monthly costs are alternative views.

Adopt the compatible gateway, Fluent Bit, OpenSearch permissions and Studio images together; the event collector requires OpenSearch configuration rather than Prometheus. Agree whether the client needs a brief maintenance window. After activation, verify Flux readiness, database roles, the collector job, source freshness and logs. MCP counts are whole-number captured invocations; incomplete delivery and provider-side billing rules can still differ from an invoice. Studio discovers tools automatically but invokes checks only through Run checks or Recheck.
